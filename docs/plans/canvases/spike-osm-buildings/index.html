Most roofs are inferred. In the generated box: 2,410 gabled, 2,030 hipped, 1,000 flat (parapets above 150 m²), 2 round hangar roofs. Houses get hipped or gabled roofs by a stable hash of their ID.

What shipping each would take

  • Shader (2–4 days): move it into the app's building layer, tune the palette and the olive cast, and line floors up with each building's base. Cesium can't pass the building type to a shader as text, so the spike packs it into the style colour.
  • Generated (2–3 weeks): build per airport at first visit or ahead of time and cache it; take ground height from elevation data instead of a browser page; compress the model (about 5–8× smaller); split it into tiles for distance detail. Facades still need terminal-specific glass and no windows on garages.
  • The two combine: generated buildings near the field, the shader on everything beyond.
What Cesium 1.140 gives a custom shader on these tiles
  • Positions and normals in model, world and eye space, and the feature ID per building.
  • Only binary batch-table properties reach the shader (parseBatchTable.js:94/110, MetadataPipelineStage.js:276, 318); text properties such as building never do.
  • The custom shader runs before style colouring (ModelFS.glsl lines 90, 96), so reading the style colour needs selectedFeatureIdStage().
  • A Y-up glTF loaded with Model.fromGltfAsync needs forwardAxis: Axis.X, or it lands rotated.
