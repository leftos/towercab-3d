TC3D-218 step 4: which facade does a fire station get?

OSM Buildings facades, feat/osm-facades at 0fc2ea1. Headless Edge, Vite dev server (vite:headless), 1596×800 canvas, building quality high, METAR clouds off. Day stills at 12:00, the night still at 22:00 local.

The question. amenity=fire_station (and building=fire_station) becomes a class rule in CLASS_RULES. Which facade class should it map to? Each lane below forces one class on the same three fire stations, from the same camera per building, so the lanes differ only in the facade the shader draws.

  • HANGAR: ribbed cladding with panel seams, no windows.
  • OFFICE: continuous window bands.
  • PLAIN: a flat wall with no openings (the domestic-garage grammar).
  • GENERIC: the punched window grid, which is what an untagged building gets today.

The buildings

All three are tagged building=yes and amenity=fire_station with no levels or height tag. Each lane forces its class on these three elements only, through the tileset style's colour; the storeys, wall height and hash stay as packed. Cameras are placed from the tower eye with the position offsets, on the bearing from the building toward the tower (turned where noted), then aimed with window.__tc3d.lookAt.

HANGAR

Grey ribbed cladding divided into wide panels, no windows. By day the stations read as sheds, the same as the maintenance hangar behind SFO Fire Station 2. At night the walls are dark, with no lit windows.

OFFICE

A continuous band of dark glazing with thin mullions along each storey. At night several bays of the band are lit warm, on every face.

PLAIN

A flat tan wall with no openings and no cladding lines. At night it is a dark brown block with no lights.

GENERIC

One row of square punched windows on a light wall, the look of any untagged building today (SFO Fire Stations 1 and 2 already show it). At night a scattering of the windows is lit.

What is approximate

  • No rule exists yet. Each class is forced on the three elements by wrapping the tileset style's colour from the page (the red channel's class code is replaced, the hash kept); no source file was changed. A real rule would type every fire station, including the off-field ones.
  • The cameras are not the tower view. They sit 85-140 m from each building so the facade can be read; from the KSFO tower eye both SFO stations are about 1.2 km away, where the controller sees far fewer pixels of each wall.
  • Night ground. At 22:00 the buildings darken and their windows light, but the satellite imagery in these headless stills stays bright.
  • Clouds are off (weather.showClouds): the METAR cloud layer drew across the walls at SFO and hid the cladding.
  • A pale band under SFO Fire Station 1's wall shows in every lane; it is the same in all four, so it does not bear on the choice.
