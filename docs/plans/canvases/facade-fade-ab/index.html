Facade window shader: fade A/B

TC3D-162 working tree, real desktop app (dev build), 1596×800 Cesium canvas. Each view shows the buildings tileset with the shader removed (before), the shader with the distance fade off (fade-off, u_fade 0) and on (fade-on, u_fade 1). Click an image for full size.

One window style on every building for now (hangars and garages included); building types come with TC3D-164.

Uniforms in every capture: u_fadeStart 0.25, u_fadeEnd 0.6 (cells per pixel), u_cover 0.30, u_glassMean (0.0249, 0.0373, 0.0540) linear. Time of day through the app's fixed-time mode: noon = 12:00 local, night = 22:00 local. Heading, pitch and FOV in degrees; offsets in metres east / north / up from the tower eye.
